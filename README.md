Tools I needed and could not find, built to use and to share. Everything below is open source.

| Project | What it is | |
|---|---|---|
| [**Project Foxy**](https://vulob1.github.io/ProjectFoxy/) | Modern, light image viewer with editor, GIF maker, manga reader, collage and compare view. | Windows · Linux |
| [**Project Ciel**](https://vulob1.github.io/ProjectCiel/) | A local AI companion to chat, talk and stream with. | Windows |
| [**Vanish Uninstaller**](https://vulob1.github.io/VanishUninstaller/) | Clean, ad-free uninstaller that finds leftovers and removes them safely. | Windows |
| [**Coreflow**](https://vulob1.github.io/Coreflow/) | Unpark your CPU cores in one click from the tray. | Windows |
| [**Chameleon**](https://vulob1.github.io/Chameleon/) | Use a Switch Pro Controller as one Xbox 360 pad, over Bluetooth or USB. | Windows |
| [**Glide**](https://vulob1.github.io/Glide/) | Frame limiter with precise frame pacing for DX11/DX12 games. | Windows |
| [**PixelPBR**](https://vulob1.github.io/PixelPBR/) | Minecraft 1.21.1 Iris shader: labPBR, pixel-art shadows, coloured light. | Minecraft |
| [**Twitch Chat Keepalive**](https://vulob1.github.io/TwitchChatKeepalive/) | Firefox extension that keeps Twitch chat from freezing. | Firefox |
| [**PS1 Recomp**](https://vulob1.github.io/PS1Recomp/) | Static recompilations of PlayStation 1 classics: [Mega Man Legends](https://github.com/VuloB1/MegaManLegendsRecomp), [Gran Turismo 2](https://github.com/VuloB1/GranTurismo2Recomp). | In development |
